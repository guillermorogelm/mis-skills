# Design Inspiration

Find two or three real references before designing. Name them, say what to take from each, then build.

The list comes from [mkdir.directory](https://mkdir.directory), a hand-picked, vote-ranked list of free design inspiration directories (no paywall, no account). For the current ranking, fetch `https://mkdir.directory/index.md` (or `https://mkdir.directory/llms.txt`); fall back to the table below if the fetch fails.

## How to use a reference

1. Pick one or two directories from the table that match the brief. Browse them (fetch the page or use a browser if one is available) and choose two or three specific sites, not the directory itself.
2. For each, write one line: the URL and the single thing to take from it (type scale, grid, colour, a section pattern, a motion idea). Never copy a site wholesale, its copy, logo or images.
3. Show those lines to the user before building, then design from them. When `art-director` or `design-taste-frontend` is also in play, the references feed their direction card or brief.

If you cannot browse, say so and give the user the two or three directory links that fit best so they can pick references themselves.
